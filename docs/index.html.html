Limitaciones

  • No incluye el caudal de los ríos (ANA): es la causa probable de las diluciones de Pisco que el modelo no reproduce.
  • Las variables externas son grillas regionales (ERA5 ~28 km), no mediciones en el muelle; coordenadas de laboratorios aproximadas.
  • El periodo de prueba 2021–2025 tuvo condiciones excepcionales (El Niño costero 2023); el error se duplicó en todos los modelos.
  • El modelo estima el mes en curso (reconstrucción de vacíos); no es un modelo de pronóstico.
